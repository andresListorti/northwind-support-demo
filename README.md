# Northwind Goods · Consumer-rights support assistant (demo)

Live demo: https://andreslistorti.github.io/northwind-support-demo/

A fictional online store with a support assistant that answers return, withdrawal and
guarantee questions for Argentina, the UK, the EU (directive level) and the US (federal),
in English and Spanish. It runs fully offline in the browser: deterministic rules,
verbatim official sources with citations, no server, no API key, no tracking.

Built with the Rights Kit engine. Try for example:

- "I bought a hoodie online 5 days ago in the UK, can I return it?"
- "Compré unas zapatillas online en Argentina, me llegaron hace 12 días, ¿puedo devolverlas?"

**Informational only. Not legal advice.** No lawyer-client relationship is created.
Information may be incomplete or outdated; check the cited official sources.
